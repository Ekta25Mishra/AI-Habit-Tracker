# 🤖 AI Habit Tracker

An AI-powered habit tracking application that helps users build better habits, monitor progress, maintain streaks, and receive intelligent insights for continuous self-improvement.

## 🚀 Features

### 👤 User Management
- User Registration & Login
- Secure Authentication
- Protected Routes
- User Profile Management

### ✅ Habit Tracking
- Create, Update, and Delete Habits
- Mark Habits as Completed
- Habit Categories
- Daily Progress Monitoring
- Streak Tracking

### 🤖 AI Assistant
- AI-powered habit suggestions
- Personalized productivity insights
- Motivation and improvement recommendations
- Habit analysis based on user activity

### 📊 Analytics Dashboard
- Completion Statistics
- Habit Consistency Tracking
- Progress Visualization
- Performance Reports

### 💬 AI Chat Support
- Interactive AI Assistant
- Habit-related Guidance
- Productivity Tips
- Personalized Recommendations

- Answer habit-related questions
